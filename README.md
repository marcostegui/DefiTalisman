Builds customizable DeFi analytics dashboards that track swaps, liquidity and token metrics in real-time for developers and traders.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiTalisman.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DefiTalisman, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
